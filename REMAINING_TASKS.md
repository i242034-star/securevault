## Left for you

### 1. Push to GitHub
Git is not installed on this PC. Install it from https://git-scm.com/download/win, then in the project folder:

```bash
git init
git add .
git status        # confirm backend/storage/, venv/ and node_modules/ are NOT listed
git commit -m "SecureVault: CP-ABE document locker"
git branch -M main
git remote add origin https://github.com/<your-username>/securevault.git
git push -u origin main
```

Make a few commits rather than one if you want a "clean commit history" (the brief asks for it).

### 2. Deploy backend on Render
1. Render dashboard → **New → Blueprint** → select the repo. It reads `render.yaml`.
2. Wait for the Docker build (~10 min: it compiles PBC and Charm).
3. Open `https://<service>.onrender.com/api/health`; it should return `{"status":"ok"}`.

Secrets (`JWT_SECRET`, `AUDIT_HMAC_SECRET`, `MASTER_KEY_PASSPHRASE`) are generated by Render. Don't paste values into git.

### 3. Deploy frontend on Vercel
1. **Add New → Project** → import the repo → Root Directory `frontend`, preset **Vite**.
2. Env var `VITE_API_BASE_URL` = `https://<service>.onrender.com/api`.
3. Deploy, then back on Render set `CORS_ALLOWED_ORIGINS` to your Vercel URL and redeploy.
